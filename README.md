# ⚔️ Astronyx Realms Online V1.6 — Teste Cloud

Este repositório foi preparado para publicar o jogo **usando apenas o navegador**, sem instalar Git nem GitHub Desktop.

## Publicar a V1.6

1. Baixe no ChatGPT o arquivo **Astronyx_Jogo_V1_6_Enviar_GitHub.zip**.
2. Abra [Enviar arquivo ao repositório](https://github.com/Night0231-creator/Astronyx-Realms-Online-Teste/upload/main).
3. Arraste **o ZIP intacto**, sem extrair, ou clique em *choose your files*.
4. Clique em **Commit changes**.
5. Aguarde o deploy automático no Render.
6. Abra https://astronyx-realms-online-teste.onrender.com

O inicializador `unpack-cloud-test.js` descompacta os arquivos do jogo em cada novo início do serviço. Ele aceita somente `server.js`, `lib/` e `public/`.

**Importante:** a hospedagem Render Free é um teste descartável. Dados locais de jogadores e campanhas podem desaparecer após reinicializações. O repositório atualmente é público: o código do jogo inserido no ZIP poderá ser acessado por terceiros. Não envie senhas, dados privados, tokens nem a pasta `data`.
