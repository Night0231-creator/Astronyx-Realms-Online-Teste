# Astronyx Realms Online — Teste Cloud

Este repositório contém uma página temporária enquanto o jogo completo V1.6 é enviado.

Para publicar a aplicação, extraia o pacote Astronyx Cloud Test e execute `publicar_github.bat` no Windows com Git for Windows instalado. O script envia o código do site, servidor e assets, sem o arquivo `.env` e sem dados de jogadores.

Ao receber o novo commit, o Render fará um novo deploy automático. **Este projeto é um teste e não deve guardar dados reais de jogadores.**
